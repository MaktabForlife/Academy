# Preserved local code variants

These code-only snapshots/patches preserve local development variants before working-folder consolidation. They are not a new application release and must not be deployed or merged without review. The root application is the exact V109.16 base.

The Student Journal implementation was tested locally and remains held/undeployed. Older Course, PDF, planning and UI variants may already have newer implementations in studio_dev; their presence here does not imply unfinished work. Each record gives its original commit and a base ancestor already present in the public repository, so selected code patches can be recovered without keeping the old Mac working folder.

Private teaching JSON, PDFs, recordings, imports, account data, credentials, local databases, build outputs and dependency folders are excluded. Private authoring material needs separately verified private storage. No Mac file was deleted or moved. No live application, media, permissions, schema or DNS was changed by this preservation.
