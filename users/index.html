Editing help

Edit names, Login IDs, WhatsApp numbers and status directly in the sheet. Select a Program or Course role cell to change Student, Teacher and Admin roles. Login IDs use letters and numbers only and must be unique. Select Reset PIN to reset a user's PIN; another Global Admin must reset your own PIN. Save all or Ctrl/⌘ + Enter saves your changes.

Select Global Users to edit Global Admin and Global Teacher designations. Save all applies these changes. Filter opens separate status controls for users, programs and courses. Another Global Admin must remove your own designation. Global Admin applies to every Program and Course. Role cells edit additional scoped roles; they cannot remove Academy-wide authority. Existing Course subscribers appear as Students. None means no assigned role or Course subscription; access to a Free Course is separate.

Inactive keeps the account and its roles. Course Student changes also update the existing Course access control. Module media subscriptions are separate and are not available yet.
