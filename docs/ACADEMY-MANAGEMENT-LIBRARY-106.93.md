# V106.93 — Management tabs and Library order

Manage Academy includes an Enrolments pill opening Manage Enrolments, with Requests and Catalogue views. Manage Enrolments uses the shared account header, LEARN/TEACH/ADMIN navigation, page refresh and Close control.

Manage Courses and Manage Programs place Enrolment requests immediately after Review & publish. The tab reuses the request inbox within the selected learning area, preserving scoped permissions, filters and manual processing. New unsaved learning areas cannot open an unscoped inbox. The standalone Admin inbox and catalogue remain available.

Published Courses show Create revision, Mark complete and Cancel Course as direct buttons. Other lifecycle actions also appear directly when available. Each action retains its existing confirmation and publication rules. Programs already use direct timetable actions; their Draft/Active/Archived lifecycle is unchanged.

The personal Library and Browse sort subject headings A–Z, then card titles A–Z, ignoring letter case and sorting numbered titles naturally. Source and module no longer precede title. Saved card-title edits and search/category filters use the same ordering.

Validation: packaged browser acceptance covers the standalone inbox, selected Program/Course tabs, scoped administrators, Course confirmation dialogs, phone/desktop layout and Library ordering across sources/modules. Backend enrolment and Course checks preserve manual access rules. No database migration or live data correction is needed.
