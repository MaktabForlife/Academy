# Cloud development and releases

Build packages with this repository's Build release package in GitHub workflow. Pushes run the pinned Studio paired compatibility check using synthetic data; it never deploys from Academy. Final paired deployment is manual in AcademyStudio after both canonical GitHub branches and frozen packages pass.

Setup and operating instructions: https://github.com/MaktabForlife/AcademyStudio/blob/studio_dev/docs/GITHUB-CLOUD-RELEASES.md

New Mac file writes require explicit permission. No Mac files are deleted. Hifz is excluded. Lesson attachment and publication stay manual.
