# Named media and Course PDFs — V107.22

Session videos use a name and YouTube link per entry. Session PDFs have an optional display name on upload and an editable name beside the original filename. Empty names use the existing filename/video label. Names appear in the lesson-media calendar, edit form, attachment choices and viewer headings. They are escaped as text. Saving an existing video keeps its asset ID; old clients sending recordingUrls retain saved names. PDF downloads retain the original filename and private R2 object.

Course Media has a separate Course PDFs section. Its collection belongs to the Course activity ID, across all of that Course’s sessions and offerings, rather than to a week, date or session. It uses an explicitly typed COURSE collection with empty date/time and no session key. Ordinary lists/timetables exclude it. Course and Global Admins manage names, uploads and independent Draft/Published/Hidden visibility; teachers and enrolled learners receive published PDF metadata only. Session discussions remain with sessions. This does not change Course paid/free access, roles, enrolments or timetable publication.

Migration 0031 adds display_name to lesson_media_assets and media_scope to lesson_media_lessons, plus one unique Course collection index. Existing rows default to SESSION and an empty optional name. No existing content, filename, asset ID, storage key, link or comment is replaced. Existing filenames remain the display fallback.
