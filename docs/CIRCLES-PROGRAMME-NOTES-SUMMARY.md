# Programme Class Notes summary

Local feature from the deployed V109.3 Source baseline. This supplies the native read contract for the Circles programme notes panel and View more popup; it does not implement their presentation, change sharing or delete older notes.

`POST /api/academy/class-notes/summary` uses the existing verified Academy account and selected workspace. Input is `{activityKey, limit?, before?}`. `limit` defaults to20 and accepts1–50. A returned `before` is an opaque encrypted next-page token; pass it back unchanged. The existing per-session Get/history cursors are unaffected. All queries stay within that exact current active programme/course. For the combined Aalimiyah/Arabic page, request each authorised programme once and merge its independently paged results; do not issue one request per circle slice.

The response contains `activityKey`, `today`, `timezone`, `window`, `notes` and `before`. The server fixes the window to the Academy's current local date minus three calendar months, clamped at month-end, starting at local midnight and ending at the request's captured instant. `window.basis` is `CREATED_AT`. Older notes and immutable versions remain stored. Callers cannot widen the window with a supplied date range.

Each returned note uses the existing note DTO plus `source`, resolved against the accepted timetable and current native sharing. Its current `canRead`, `canPost` and `canModerate` apply to the source. Admin-Learn remains read-only; unresolved contexts cannot offer posting/editing. Bodies and author names are fetched only after sharing checks pass. Withdrawn notes are excluded, including the retention workflow's atomic WITHDRAWN/null-pointer transition before PURGING versions. Retention's timetable version-ID additions must survive composition; this feature introduces no purge or retention job.

Current native programme/workspace eligibility is checked before reading any candidates; an out-of-scope account receives403 without an existence cursor. An indexed candidate page is then selected before resolving current lesson sharing. A page may therefore contain fewer visible notes, or none, and still return a `before` cursor. Continue only on a deliberate View more action, preserving the opaque last-scanned cursor. AES-GCM hides and authenticates its internal note ID/timestamp; its key derives only from the existing server session secret with a distinct purpose. Additional authenticated data binds the account, native session/credential epoch, programme, workspace, selected class, pinned head and stable calendar window. A forged or cross-boundary token is rejected before a candidate query. There are no cursor database writes or browser keys. Do not assume an empty page means history ended, automatically exhaust all pages, or display candidate cursor metadata as notes. The existing per-session Class Notes actions remain unchanged.

Apply additive Core migration `0022_class_notes_summary.sql` before activating a matching Source/Studio frontend. It adds only `class_notes_programme_history(activity_key,state,created_at DESC,note_id DESC)`. No new table, column, coordinator method or SQL supplied by the browser is introduced. Missing index gives a safe retryable503 through the existing HTTP error boundary. The prior application pair remains compatible with the index. Deployment is owned by optimisation under the complete tested paired-release approval; this feature has not been deployed.

Verification includes actual Source HTTP and split-store/coordinator paths, class/account/session/credential-epoch checks, scoped/Teacher/Admin-Learn sharing, tied-timestamp pagination, calendar boundaries, missing-index handling, foreign-key integrity and unchanged existing note writes/history. The cost tool runs disposable Miniflare/workerd D1 with a fixed small accepted timetable, captures API and coordinator D1 metadata, and compares a warm request with4000older same-programme notes plus4000unrelated-programme notes. This measures that fixture, not hosted billing or growth in the accepted timetable/rights projections themselves.
