# Academy V107.1 — Direct HifzHelper entry

LEARN and TEACH now show one HifzHelper shortcut instead of separate Hifz and HifzHelper buttons. The same choice appears when switching Programs from another learning area. Following the shortcut uses the existing secure Academy sign-in handoff.

The old Hifz page links are removed from both workspaces and the shared navigation. HifzHelper is the only Hifz entry link. A previously saved bookmark cannot reopen the redundant page. The Hifz Program and its memberships, roles, lessons and records are retained. Hifz lessons remain in the combined Academy timetable. ADMIN Program management and assessment management remain available.

No database, PIN, profile synchronisation or Hifz V5.0 changes are required. Deployment targets the Academy development website and its matching development Worker only.

Program and Course workspace headings use a narrower title column, letting long titles wrap and giving the Programs and Courses boxes more width. Smaller screens retain their stacked layout.

Validation: the existing entrance UI suite covers student, teacher, Program Admin and Global Admin shortcuts, old links, other Programs and Courses, management access, invalid login IDs, sign-out and the absence of extra API requests.
