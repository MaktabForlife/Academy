# Academy answer statuses and Ready

Final rules for staged implementation authorised on 22 October 2026. See the [final implementation brief](README.md).

Question papers: Waiting for submission → Drafted → Returned → Approved → Published → Released. Returned is the correction outcome, not a compulsory pass-through stage.

Answers: Waiting → Uploaded → Checked → Ready for assessment → Assessed → Moderated → Marks released. Derive real received/checked/marked counts from current ordinary records; preserve returns/history rather than forcing a linear completion.

Ready is manually selectable when all expected answers have been uploaded AND checked, OR on the next Academy day. For assignments use the effective due date as the date reference, not publication or first access. Availability never automatically sets Ready.

If received answers remain unchecked, warn Admin and offer Cancel / Continue anyway. Cancel changes nothing; Continue sets Ready without checking missing/unchecked papers or releasing results. Recheck current counts/revision before accepting the decision. The warning cannot bypass same-day ineligibility.

Next-day Ready may have zero uploads. Display the true expected/received/checked/missing counts. An empty set is never Checked/Assessed/Moderated/Marks released. Admin can receive/upload later manual work through ordinary controls; no per-case readiness system or automatic already-released-result workflow.

Normal staff/assigned-examiner/current-answer and ordinary moderation checks remain. Admin's manual-finalisation permission is an explicit Admin action, not examiner impersonation. Register tracking or draft setup cannot set Ready/release.
